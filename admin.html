How It Works
Everything a new manager needs to know to run this system.
1
Upload a Window Sticker PDF
Go to Upload Sticker in the sidebar. Drop in the PDF window sticker for any Mazda vehicle. Claude AI reads it and automatically extracts the model name, year, all trim levels, MPG figures, horsepower, engine, drivetrain, towing capacity, and available colors.
📄 Window stickers come from Mazda's dealer portal or are printed from the vehicle. Any standard Mazda window sticker PDF works.
2
Review and Correct the Extracted Data
After extraction a review screen shows everything Claude found. Check each field — Claude is usually accurate but not perfect. You can edit any value, add or remove trims, and adjust colors before saving.
💡 The Slug field is a behind-the-scenes URL identifier. Leave it as the auto-generated value unless you have a reason to change it.
3
Publish or Save as Draft
Publish to Site makes the vehicle immediately visible to customers. Save Draft saves it but hides it — useful if you want to add images first. Toggle published/unpublished anytime from the Vehicles page.
4
Upload Color Photos
Go to Manage Images, select the model, and upload a photo for each color card. Exterior colors need a PNG with a transparent background — these display as floating car images on the customer site. Interior colors take any cabin photo.
🎨 Use the + Add Color button to add colors that weren't on the window sticker — useful for colors added later or missed during extraction.
5
Editing After Publishing
You never need to re-upload a sticker to make corrections. From the Vehicles page, click Edit Trims to update MPG, horsepower, features, or any other spec. Click Images to manage photos. Use Delete Color on the Images page to remove incorrect colors.
⚠️ Re-uploading a sticker for an existing model will overwrite its data. Always use Edit Trims for corrections instead.
6
What Customers See
The customer site at mos-red.vercel.app automatically shows every published vehicle with a tab in the nav bar. Customers can browse trims, see MPG and specs, click color swatches to swap the car image, and view interior photos. No pricing is shown anywhere.
